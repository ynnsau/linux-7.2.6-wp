# Batched dirty sampling and ARM: validation and installation

Installed `7.2.6-cmdp-batch-production` on BMP after all seven VM suites passed on
both debug and production images. **2,082 TAP checks and 144 generated-graph
BFS/PR correctness verifications passed.** GRUB contents and metadata, old boot
files, boot links, running kernel and boot ID remained unchanged. No host reboot
or native CMD-P workload was performed during this round.

## Implementation

- Dirty sampling retains at most 64 referenced, trylocked folios in one VMA,
  clears each PTE's dirty state under its lock, then performs one covering range
  flush. New quiet epochs become valid only after that flush completes.
- ARM prepares a bounded batch, protects PTEs under a shared MMU notification and
  fast-pin exclusion sequence, flushes once, checks each candidate's pins and
  references, then publishes ACTIVE ownership. Partial failures and STOP drain
  every staged entry; modified PTEs are flushed before cleanup.
- Scanning reuses the probe reference, looks up the VMA once per chunk, skips
  surviving ARM pages before page lookup under VMA fault exclusion, and groups
  scan-only accounting updates. Exact ownership transitions stay immediate.

One worker, page eligibility, safety checks, public reporting fields and the
10-second policy remain intact. The legacy explicit multi-alias operation keeps
its synchronous per-alias handling. Existing mapping, cancellation and recovery
fixes remain in place. Kernel behavior is frozen at
`2919ec3ef02fe690a51a1bfded34845d9ce1eb10`. See
[BATCHING.md](../tools/testing/selftests/cmdp/BATCHING.md) for ordering and fixtures.

## Reporting semantics

`dirty_status.flushes` retains its existing page unit (equal to resets). New global
debugfs counters `dirty_flush_batches/pages` and `arm_flush_batches/pages` separate
actual range-flush calls from page coverage. Shared flush time is counted once.
`arm_ns` sums entry arming latencies; entries overlap within a batch, so it is not
CPU time or end-to-end overhead. `scan_active_skips` and `scan_page_lookups` expose
avoided page lookups. Test pause counters are inactive unless explicitly configured.
